# PRD v2 — School AI 부스 수강생 활동 플랫폼 (웹 슬라이드 앱 + 3D 지식그래프)

버전 2.0 / 2026-08-05 / 강사: 이승엽(장평중, 정보) / 구현: Claude Code / 배포: Vercel

v1 → v2 변경: ① 성취기준 매핑을 대단원 수준 → **성취기준 코드 수준**으로 상향(도트밸리는 강사가 직접 매핑 완료) ② 탐색기를 **3D 지식그래프**로 교체 ③ 오프라인 제약 삭제(행사장 네트워크 안정) ④ 사례 파트에 **시연용 차시 웹앱**(별도 PRD) 데모 연결 ⑤ 청중을 "대부분 중학교 정보 교사"로 확정하고 성취기준 기반 재구성을 전면에 배치.

## 1. 배경과 목적

2026 과·수·정 콘퍼런스(8/6~7, 부산 BEXCO) School AI 부스, 1일차 중학 회차 2개를 진행한다.

- 2회차 12:00~12:30 — 「도트밸리 속 버그를 잡아라」
- 5회차 15:00~15:30 — 「S.O.S 세계수를 구하라」

회차당 30분: 접수 3분 → 콘텐츠 체험 20분 → 학교 적용 사례 5분 → 의견조사(QR)·기념품 2분. 수강생 약 15명, **대부분 중학교 정보 교사**, 좌석마다 노트북.

핵심 메시지: "이 콘텐츠를 **내 정보 수업에 어떻게 녹일까**." 정보 교사의 수업 재구성은 성취기준에서 출발하므로, 이 플랫폼의 중심축은 **성취기준 ↔ 콘텐츠 활동의 완전 매핑**과 이를 탐색하는 **3D 지식그래프**다. 두 가지 활용 경로를 명확히 제시한다:

1. **전환기 교육**(기말 이후 등): [학습 도장 모으기]로 전체 완주 + 이수증
2. **정규수업 재구성**: 성취기준 → 관련 차시 → 원하는 활동 딥링크만 뽑아 재조합 → 나만의 차시 웹앱(시연 데모 제공)

## 2. 데이터 (동봉 2개 파일, 빌드 타임 임포트)

- `sai-content-links.json`: 도트밸리 10차시 128활동 + 세계수 8차시 104활동. 활동별 `{no, title, link, type: video|interactive}`. 링크는 `?lock=false` 딥링크(로그인 불필요, 새 탭). 추가 필드: 콘텐츠별 `guides.student`·`guides.teacher`(학생용/교사용 매뉴얼 PDF 직다운로드 URL, 무인증 확인 완료), `saiCatalog`(School AI 플랫폼 홈 + 초3·중3·고4개 콘텐츠 원본 페이지 링크 + 고교 프로젝트 5종 제목).
- `sai-standards-map.json`: ① 2022 개정 중학교 정보과 성취기준 **전문 25개**(9정01~9정05, 대단원명 포함) ② 차시별 성취기준 매핑 `{primary[], secondary[], rationale, source}`. 세계수는 `source: official`(교사용 매뉴얼 명기), 도트밸리는 `source: instructor`(강사 재구성안 — UI에 배지로 구분 표기).

런타임 SAI API 호출 금지(익명 토큰 필요). 그래프 라이브러리 등 의존성은 npm 번들로 포함(행사장 네트워크는 안정적이나 로딩 속도를 위해).

### S3. 3D 지식그래프 — 핵심 화면 2 (차별화 요소)
정보 교사가 "성취기준에서 출발해 활동까지 역방향 검색"하는 화면. 라이브러리: `3d-force-graph`(three.js 기반, npm).

**노드 계층(5단계)**: 대단원(5) → 성취기준(25) → 콘텐츠(2) → 차시(18) → 활동(232)
**간선**: 대단원—성취기준(교육과정 구조) / 성취기준—차시(매핑, primary 실선·secondary 점선) / 콘텐츠—차시(소속) / 차시—활동(구성)

**인터랙션 요구사항**:
1. 초기 상태: 대단원 5개 + 성취기준 25개만 표시(활동 232개를 처음부터 다 그리면 헤어볼 — 점진 확장 방식 필수)
2. 대단원 클릭 → 카메라 포커스 + 해당 성취기준 하이라이트
3. 성취기준 클릭 → 매핑된 차시 노드 확장·연결(콘텐츠 허브 노드 경유), 사이드 패널에 성취기준 전문 + 연계 차시 목록
4. 차시 클릭 → 활동 노드 확장, 사이드 패널에 활동 리스트(각각 딥링크 버튼 + video/interactive 아이콘)
5. 활동 클릭 → 사이드 패널에서 [활동 열기](새 탭) + [재구성 바구니에 담기]
6. **재구성 바구니**: 담은 활동들이 하단 트레이에 쌓임 → [내보내기] 시 "선택 활동 제목+딥링크+연계 성취기준" 텍스트/마크다운 복사 — "이 목록을 바이브 코딩에 넣으면 차시 웹앱이 됩니다" 멘트와 함께 사례 파트의 복선
7. 노드 색: 대단원별 5색 고정, 콘텐츠·차시·활동은 소속 대단원 색의 명도 변화. 도트밸리 매핑 간선에는 "강사 재구성안" 구분(범례 표기)
8. 검색창: 성취기준 코드·활동 제목 검색 → 해당 노드 포커스
9. 폴백: `2D 목록 보기` 토글(차시별 아코디언 + 성취기준 칩 필터) — 그래프가 부담스러운 사용자용

### S4. 학교 적용 사례 & 수업 설계 (5분, 발표 파트)
3장 구성:
1. **전환기 교육 — 통째로 완주**: [학습 도장 모으기] 전체 진행 + 이수증. 운영 팁(이탈 시 처음부터 → 차시 단위 운영, PDF 저장, 모바일 불가).
2. **정규수업 재구성 — 성취기준에서 출발**: S3 그래프 화면 재등장 → "9정02 데이터 단원 차시를 만든다면?" 시나리오 → 재구성 바구니 시연 → **[시연용 차시 웹앱 열기]** 버튼(외부 URL 상수 `DEMO_LESSON_URL`, 별도 PRD로 제작·배포되는 실물 데모). 시연 웹앱에서 수강생이 직접 학생 입장으로 활동·형성평가 → 강사 빔에 교사 대시보드 실시간 갱신을 보여주는 것이 이 파트의 하이라이트.
3. **공개수업 실전 사례 — 도트밸리 5차시 이미지 인식(사물 분류)**: 실제 공개수업 흐름 타임라인(도입 영상 → 수집·전처리·라벨링 게임 → 테스트·성능 개선 → 우리 학교 문제 적용 토의). "체험하신 M1이 바로 이 차시" 연결. 설문 6번 예열(정규수업/창체/동아리/방과후 매핑 한 줄).

## 기술 스택·운영 (공통 확정)

- DB/스토리지: **Firebase** (Firestore + Storage)
- AI 기능: **Gemini API** (Vercel 서버 라우트 경유, API 키는 환경변수 — 클라이언트 노출 금지)
- 배포: **Vercel** / 코드 공유: **GitHub** (README에 환경변수 목록 `.env.example` 포함)
- 디자인: 현 PRD의 디자인 방향대로 1차 구현. 추후 `design.md` 제공 시 동적 디자인으로 개편 예정이므로, **테마 토큰(색·타이포·모션)을 상수/CSS 변수로 분리**해 교체 비용을 최소화할 것

### 데이터 모델 (Firestore)
```
booth/{sessionId}/participants/{pid}  { school, name, joinedAt }
booth/{sessionId}/progress/{pid}      { m1:bool, m2:bool, m3:bool, updatedAt }
config/booth { teacherPin }
```
- sessionId: `dotvalley-1200`, `sos-1500`. pid는 입장 시 생성해 localStorage 보관
- 보안 규칙: 본인 문서만 쓰기, 대시보드 읽기는 이름·소속·도장 필드만. 개인정보는 소속·성함뿐이며 회차 리셋으로 즉시 파기

## 6. 비기능
- Next.js + Firebase (시연용 차시 웹앱과 동일 스택 — 동일 리포지토리 모노레포 구성 가능, Firebase 프로젝트 공유)
- 콘텐츠 데이터(JSON 2종)는 빌드 타임 임포트, 의존성은 npm 번들(CDN 런타임 의존 금지)
- AI 기능은 본 앱 범위에 없음. 추후 추가 시 Gemini API를 Vercel 라우트로 사용
- 3D 그래프 초기 로딩 2초 내(활동 노드 지연 생성)
- 키보드 포커스 가시화, 명도 대비 준수

## 7. 디자인 방향
- 회차 테마: 도트밸리=탐험 그린+도트 모티프 / 세계수=숲 앰버+잎사귀 모티프. 본문은 절제된 카드 UI
- 지식그래프는 다크 배경(3D 가독성) + 대단원 5색 범례 고정 노출
- "교사의 눈" 문구는 눈 아이콘+별색, 도트밸리 매핑엔 "강사 재구성안" 배지 일관 표기
- 푸터: 이승엽(장평중학교) · 도트밸리 5·8·10차시 집필

## 8. 수용 기준
1. 회차 선택 후 새로고침에도 유지
2. 도트밸리 M1 딥링크 4개가 새 탭에서 실제 활동으로 열림(전체 232 딥링크 렌더)
3. 그래프에서 9정02-03 클릭 → 세계수 2차시·도트밸리 2차시 확장, 도트밸리 간선에 재구성안 구분 → 차시 클릭 → 활동 → 딥링크 열기까지 클릭 4번 이내
4. 재구성 바구니에 활동 3개 담고 내보내기 → 제목+링크+성취기준이 포함된 마크다운 복사됨
5. 도장 3개 완료 배지·리셋 동작
6. 발표 모드 키보드 전환 + 타이머 동작
7. `SURVEY_URL`·`DEMO_LESSON_URL` 상수 각 1곳 교체로 반영
8. 자료실에서 매뉴얼 PDF 4종이 클릭 즉시 다운로드되고, 초·중·고 콘텐츠 링크가 원본 페이지로 열림
9. 소속·성함 입장 후 미션 도장 체크 시 `/teacher` 그리드에 1초 내 반영, 새로고침 시 본인 상태 복구, 회차 리셋 시 데이터 일괄 삭제

## 9. 범위 제외
- 시연용 차시 웹앱 자체(별도 PRD `PRD-lesson-demo.md`로 제작, 본 앱은 링크만)
